# source/

The reconstruction. Tree mirrors GBD's as recorded in the PDBs:

```
missions/{shared,strategy02,instant,deathmatch01,luamission,vsrcore}
```

Every file begins with a `// PROVENANCE:` line (format in `../PROVENANCE.md`); state per file in
`../STATUS.md`. 66 files; all are `stub` from the task-6 scaffold until a port task moves them.

## What the scaffold generated (task 6)

`tools/scaffold_from_manifest.py` wrote every file from GBD's PDBs (`tools/pdb_types.py`) and the
ancestors (`reference/manifest/FILE_MAP.md`):

- **Headers** — PDB-true declarations: class kind, base, members in offset order with PDB access,
  static members, nested types, methods in declaration order with PDB access / `virtual` / `static` /
  `const`, parameter names where the PDB kept them (`param_N` where the compiler dropped an unused
  one), enums with GBD's values (`Hash_GOClass`, `Hash_BZCClass`, …), free-function and namespace
  declarations. Includes / forward declarations are derived from the types used.
- **.cpp** — one definition per function the PDB records, body = safe default + a
  `// DECOMPILE:` pointer (`file:lines @VA` from the Strategy02 decompile set, or the symbol
  address / `pending (task 13)` for the other DLLs). Where the ancestor defines the same function
  its body follows under `#if 0 // SEED: <path>:<lines>` for the porter.

Counts at scaffold time: 1,205 stubbed functions, 387 ancestor seeds, 857 line pointers.

## Scaffold conventions (remove / tighten while porting)

| Token | Why | What the port does |
|---|---|---|
| `friend struct VsrLayoutCheck_<Class>;` | MSVC enforces access in `offsetof`; the friend lets `vsr_layout_asserts.h` check private members (QA gate 2). No layout effect. | keep until gate 2 is retired after parity |
| nested types emitted `public:` | the PDB records member access but not nested-type access | restore the ancestor's `private:` where it had it |
| stub parameters as `type /*name*/` | keeps `-W4` silent without touching the signature | uncomment as the body is written |
| `#pragma warning(disable: 4505)` | file-static trampolines are unreferenced until their caller is ported | delete with the port |
| `#if 0 // SEED: …` | the ancestor's body, verbatim, next to the stub | becomes the body (brought to VSR), then the `#if 0` goes |
| `static X s_stub = X(); return s_stub;` | reference-returning stub | replaced |
| `#define VSR_LAYOUT_CHECK_<Class>` / `#include "vsr_layout_asserts.h"` at the end of a class header | gate 2 hook | keep |

`shared/vsr_layout_asserts.h` is generated by `tools/layout_asserts.py`; it is the only file here
that is not GBD's. Default arguments, inline-ness of small methods and comments are not in the PDB
and come back from the ancestors during the port.

Regenerate a still-`stub` file after a manifest change with `python tools/scaffold_from_manifest.py`;
files whose provenance line no longer says `status: stub` are left alone (`--force` overrides).
